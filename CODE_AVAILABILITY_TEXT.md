# Code availability

Analysis and figure-generation code is available at https://github.com/yongqih/virtual-cell-intervention-geometry under the MIT License. The implementations cover intervention geometry, residual coordinates, temporal propagation, same-target cross-context transfer and control-cell fluctuation analyses. The archived code is available at https://doi.org/10.5281/zenodo.22692691, with matching source data at https://doi.org/10.5281/zenodo.22692573.
