# Code Availability

The custom analysis and figure-reproduction code used in this study is publicly available at https://github.com/yongqih/virtual-cell-intervention-geometry. The final audited release, including the frozen configurations, reproducibility manifests, release validators, and retained implementations used in this study, is available on Zenodo at https://doi.org/10.5281/zenodo.21998676. Third-party software is referenced by dependency manifests and is not redistributed. The code is distributed under the MIT License.
