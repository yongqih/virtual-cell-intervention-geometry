# Code Availability

The custom analysis and figure-reproduction code used in this study is publicly available at https://github.com/yongqih/virtual-cell-intervention-geometry. The repository includes the frozen RPE1 natural-fluctuation source-anchor audit, the Supplementary Figure 5a–h renderer and a derived-data-only figure workflow that does not load or redistribute the third-party RPE1 H5AD. The version-specific v1.1.0 code archive is available on Zenodo at https://doi.org/10.5281/zenodo.22005122. Third-party software is referenced by dependency manifests and is not redistributed.
